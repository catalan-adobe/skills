# Product Template Analysis

## Representatives

Two product pages (Alpha Grinder at €89, Bravo Grinder at €149) demonstrate
template structure.

## Decomposition

Product hero section extracted as default content; specs table extracted as
`specifications` block.

## Blocks

One block: `specifications` — a two-column table with label and value, from
`table.specs tr` rows.

## Default Content Decisions

Product hero section (heading, image, price, lead text) migrated as default
content area.

## Not Migrated

Breadcrumb navigation not migrated; header/footer markup not migrated.

None at this stage.
